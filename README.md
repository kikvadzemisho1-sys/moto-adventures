# Moto Adventures 🏍️

მოტომოგზაურობაზე შექმნილი ერთგვერდიანი სასწავლო ვებსაიტი.
პროექტის მიზანია HTML-ისა და CSS-ის პრაქტიკა.

## რა არის გვერდზე

- შესავალი სათაურითა და აღწერით
- ქალაქში გასეირნებისა და შორი მარშრუტის ფოტობარათები
- ღილაკი, რომელიც მოგზაურობის ფოტოსთან გადადის
- დიდი ფოტო წარწერით
- ფუტერი
- სხვადასხვა ზომის ეკრანზე მორგებული განლაგება

## გამოყენებული ტექნოლოგიები

- HTML5 — გვერდის სტრუქტურა
- CSS3 — ვიზუალური გაფორმება
- CSS Grid — ბარათების განლაგება
- Media Queries — ეკრანის ზომაზე მორგება

## პროექტის ფაილები

- `index.html` — მთავარი გვერდი
- `style.css` — გვერდის სტილები
- `images/` — გამოყენებული ფოტოები
- `README.md` — პროექტის აღწერა
